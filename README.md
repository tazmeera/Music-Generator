# AI Music Generator (Python)

A procedural music generation system that creates unique compositions and exports them as MIDI files.

---

## 🚀 Features
- Multiple music genre patterns  
- Tempo control  
- MIDI file generation  
- Automatic file saving  

---

## 🧠 Tech Stack
- Python  
- MIDIUtil  
- Algorithmic music generation  

---

## 📌 Overview
This project demonstrates algorithmic and rule-based music generation techniques to produce structured musical outputs programmatically.
