# AI Music Generator

A professional AI-inspired Music Generator developed for the CodeAlpha Artificial Intelligence Internship using Python, Tkinter, and MIDIUtil.

## Features

- Generate unique MIDI music automatically
- Multiple music genres:
  - Classical
  - Jazz
  - Pop
  - Piano
  - Blues
  - Lo-fi
  - Rock
- Adjustable tempo (60–200 BPM)
- Select music length (4, 8, 16, or 32 bars)
- Optional chord accompaniment
- Multi-track MIDI generation
- Motif-based melody creation
- Save generated music to any folder
- Open generated MIDI files directly
- Modern dark-themed GUI

## Technologies Used

- Python
- Tkinter
- MIDIUtil

## Installation

Install the required library:

```bash
pip install midiutil
```

Or install using requirements.txt:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python music_generator.py
```

## How It Works

1. Select a music genre.
2. Choose the tempo (BPM).
3. Select the number of bars.
4. Enable or disable chord accompaniment.
5. Choose a save location.
6. Click **Generate Music**.
7. The application creates a MIDI file automatically.
